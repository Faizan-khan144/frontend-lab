# BrainDuel - Quiz Game

A timed trivia game with four categories, scoring and animated results.

## Features

- 4 categories with 10 random questions per game
- 20-second per-question countdown with color-coded timer
- Instant answer feedback and score tracking
- Correct / wrong / time statistics
- Animated results ring with performance grade
- Retry or change category options

## Run

Open `index.html` in any browser.
