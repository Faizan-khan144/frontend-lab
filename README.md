## Features Across the Lab

- **Responsive** — every project is mobile-friendly with adaptive layouts
- **No dependencies** — pure HTML, CSS and JavaScript only (weather app uses the free Open-Meteo API)
- **Persistence** — bookstore, todo-app, calculator, recipe-app and cloth-store save data in `localStorage`
- **Accessibility touches** — keyboard support in gallery, calculator and quiz
- **Lightweight** — no images or fonts to download; visuals are generated with CSS

## Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Faizan-khan144/frontend-lab.git
   ```
2. Navigate to any project folder, e.g. `bakery/`.
3. Open `index.html` in your browser.

> The weather-app fetches live data from the free [Open-Meteo](https://open-meteo.com) API, which requires an internet connection. All other projects work fully offline.

## Tech Stack

- HTML5 semantic markup
- Modern CSS (Grid, Flexbox, CSS variables, animations)
- Vanilla JavaScript (ES6+)
