# Simmer - Recipe Studio

A recipe collection with search, favorites and interactive instruction scaling.

## Features

- Search by recipe name or ingredient
- Meal-type filter chips (Breakfast / Lunch / Dinner / Dessert)
- Star recipes to build a favorites list in `localStorage`
- Recipe modal with ingredients and step-by-step method
- Servings adjuster that rescales ingredient quantities
- Fully responsive

## Run

Open `index.html` in any browser.
