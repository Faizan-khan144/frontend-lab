# Lumina Gallery

A masonry photo gallery with category filters and a full-screen lightbox.

## Features

- Responsive masonry layout built with CSS columns
- Category filters (Nature / City / People / Animals)
- Lazy-loaded images
- Lightbox with prev / next navigation
- Keyboard support (arrows and Escape)
- Hover overlays with photo captions

> Photos are served from the free picsum.photos placeholder service.

## Run

Open `index.html` in any browser (internet required for photos).
