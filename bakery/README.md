# Golden Crumb Bakery

A warm, artisan bakery landing page built with plain HTML, CSS and JavaScript.

## Features

- Sticky navigation with mobile menu
- Hero section with bakery-brand styling
- Product grid generated from a JS data array
- Category filter (Bread / Pastry / Cake)
- Working cart counter with add feedback
- Scroll-reveal animations via IntersectionObserver
- Fully responsive

## Run

Open `index.html` in any browser.
