# Sahara Cloth Co.

A minimal e-commerce clothing store with a fully working shopping bag.

## Features

- Hero section and category collections
- Product filtering by category (Men / Women / Accessories)
- Sorting by featured, price and rating
- Add-to-cart with quantity controls
- Persistent cart in `localStorage`
- Slide-out bag with live subtotal
- Checkout flow with order confirmation
- Toast feedback and responsive layout

## Run

Open `index.html` in any browser.
