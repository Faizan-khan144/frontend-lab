# Pulsewave Player

A music player with a live in-browser synth engine — no audio files needed.

## Features

- Music generated live with the Web Audio API (oscillators + sequencer)
- 3 synth tracks with different tempos and keys
- Spinning vinyl record animation
- Real-time waveform visualizer
- Play / pause, previous / next, volume control
- Interactive clickable playlist
- All styling is custom CSS

## Run

Open `index.html` in any browser (Chrome / Edge / Firefox recommended).
