# SkyCast Weather

A weather dashboard that pulls real data from the free Open-Meteo API — no API key required.

## Features

- Search any city worldwide
- Geolocation lookup button
- Current temperature, feels-like, humidity, wind and pressure
- Dynamic background theme per weather condition
- 5-day forecast grid
- Celsius / Fahrenheit toggle
- Fully responsive

## Run

Open `index.html` in a browser with an internet connection.
