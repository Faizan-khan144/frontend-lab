# Calcore - Smart Calculator

A scientific calculator powered by a custom expression parser — no `eval()` used.

## Features

- Full arithmetic with percentages and power operator
- Scientific functions: sin, cos, tan, ln, log, sqrt
- Constants, factorials and brackets
- Keyboard support for digits and operators
- History panel persisted in `localStorage`
- Dark / light theme toggle
- Proper error handling (division by zero, invalid input)

## Run

Open `index.html` in any browser.
